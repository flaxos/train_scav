TRAIN_SCAV — SPRINT 5A PHYSICAL TRAIN INTERIORS

This overlay is intended for the accepted Sprint 4.5 worktree.

Scope:
- explicit carriage interior metadata
- per-end gangways
- safe non-boardable defaults for unknown rolling stock
- survivor host carriage + local interior position
- physical walking L -> A -> B through compatible gangways
- continuous visual crossing between moving carriage doors
- actual clicked local destination inside a carriage
- split consist immediately blocks impossible interior routes

Deliberately NOT included:
- needs / hunger / rest / health
- skills / roles / automatic jobs
- inventory / hauling / crafting
- new rail traversal or turnout mechanics

Run automated tests before GUI UAT. Do not commit Sprint 5A until both pass.
